# Contact

A minecraft mod adding things related to "contact"

## Features:
- The Emitter:
  - When flying you can emit particles to leave signs in the sky
  - Crafted from one stick and two endrods (diagonal)
- The Contactor:
  - Without the contactor you can't write anymore in the chat (incl. /say commands etc.)
  - Crafted with one iron and two redstone above, this device allows you to stay in contact with your friends
  - Animated texture
- Private Books:
  - When a written book is titled "@"+player name only this player can read the book
- Youth Center:
  - A new structure
- Hugging:
  - You can hug or pet animals now by pressing `h`
